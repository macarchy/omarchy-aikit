## Conflict hot-spots (merge-with-main resolutions)
| File | Why it collides | Resolution |
|------|-----------------|------------|
| `CHANGELOG.md` | release-please appends; every branch carries its own entry | **regenerate** — let release-please rewrite it; never hand-merge |
| `.release-please-manifest.json` | every release bumps the one version | take the **higher** |
| `README.md`, `docs/` | parallel features document themselves | **union** |
| `tests/` | both sides append cases | **union** |
| `share/strings.json` | every feature adds strings | **union**, then re-run the jq gate |
| `PKGBUILD` | version bumps | take the **higher** |
- **Rule of thumb:** union additive files, regenerate derived files, take-the-higher for the version;
  same-logic-both-sides is a real semantic conflict — understand both intents or stop.
